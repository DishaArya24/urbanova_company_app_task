# Urbanova Company App

## 📱 Project Description

Urbanova Company App is a Flutter-based mobile application
developed to showcase Urbanova Technologies' company profile,
services, portfolio, and enquiry functionality.

The application focuses on responsive UI, reusable components,
animations, structured data handling, and clean navigation.

---

- Git
- GitHub
- Android Studio

### Flutter Version

## 📊 Data Handling

Service information is stored in a JSON file and loaded
dynamically using Flutter's asset system.

JSON → Data Service → Service Model → UI

## 🚀 Setup Instructions

### Prerequisites

- Flutter SDK
- Android Studio
- Android Emulator or physical Android device

### Steps

1. Clone the repository.
2. Open the project in Android Studio or VS Code.
3. Run:

flutter pub get

4. Connect an Android device or start an emulator.
5. Run:

flutter run
